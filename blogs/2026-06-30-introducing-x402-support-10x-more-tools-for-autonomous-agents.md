Apify added x402 agentic payment protocol support, letting AI agents pay for more than 20,000 Apify Actors with USDC on Base without pre-provisioned API keys, a 10x jump from roughly 2,000 previously payable tools. HTTP 402 responses trigger automatic payment authorization via Coinbase's Agentic Wallet CLI or mcpc, supporting both fixed-price and variable-cost billing schemes.
